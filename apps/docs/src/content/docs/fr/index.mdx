ZenithDocs transforme un dossier de fichiers Markdown et MDX en un site de documentation rapide. Chaque page est prérendue en HTML et CSS, et le JavaScript n'est envoyé que pour les rares interactions qui en ont besoin.

## Pourquoi ZenithDocs ?

Les gros frameworks de documentation apportent beaucoup de fonctionnalités, et souvent beaucoup de JavaScript. ZenithDocs vise le même confort de rédaction, tout en livrant un site aussi léger qu'une page écrite à la main.

- **Statique par principe** : chaque page est du HTML. La sidebar, le sommaire, les accordéons et les arborescences de fichiers fonctionnent sans JavaScript.
- **Conventions familières** : les pages sont ordonnées par des fichiers `meta.json`, avec la même syntaxe que Fumadocs.
- **Thémable** : les styles reposent sur les tokens Lumos et les couches CSS, donc votre propre CSS l'emporte toujours.
- **Bâti sur Astro 7** : le Markdown passe par le pipeline Sätteri écrit en Rust, et le code est coloré au build par Shiki.

:::tip[Cette page est traduite]
Les pages sans traduction restent accessibles en français : elles s'affichent dans la langue par défaut, avec un bandeau qui le signale.
:::

## Budget JavaScript

| Fonctionnalité            | JavaScript                                 |
| ------------------------- | ------------------------------------------ |
| Sidebar et menu mobile    | Aucun, grâce à l'API Popover               |
| Thème sombre              | Un court script en ligne                   |
| Bouton copier le code     | Un court script en ligne                   |
| Sommaire                  | Un petit module de suivi du défilement     |
| Onglets                   | Un petit composant web, seulement si utilisé |
