---
title: Frontmatter
description: Fields available at the top of each page.
icon: tag
---

```mdx
---
title: Getting started
description: Learn the basics.
icon: rocket
sidebar:
  label: Start here
---
```

| Field             | Type                | Description                                                  |
| ----------------- | ------------------- | ------------------------------------------------------------ |
| `title`           | `string`            | Page title, required                                         |
| `description`     | `string`            | Shown under the title and used as meta description           |
| `icon`            | `string`            | Name from the [icon set](/reference/icons/), shown in the sidebar |
| `full`            | `boolean`           | Use the full content width, without the table of contents    |
| `toc`             | `boolean`           | Show the table of contents, `true` by default                |
| `draft`           | `boolean`           | Only show the page in development, leave it out of builds    |
| `sidebar.label`   | `string`            | Label used in the sidebar instead of the title               |
| `sidebar.hidden`  | `boolean`           | Hide the page from the sidebar                               |
| `sidebar.badge`   | `string \| object`  | Short label next to the page in the sidebar, see [badges](#sidebar-badges) |
| `prev`            | `string \| object \| false` | Change or hide the link to the previous page, see [pagination](#pagination) |
| `next`            | `string \| object \| false` | Change or hide the link to the next page                    |
| `og`              | `object \| false`   | Change, replace or remove the [social image](/open-graph/#per-page) |
| `editUrl`         | `string \| false`   | Override or disable the [edit link](/reference/configuration/#editlink) |
| `lastUpdated`     | `Date \| false`     | Override or disable the [last updated](/reference/configuration/#lastupdated) date |

## Sidebar badges

A badge points readers to a page, such as a new feature. It takes the accent color, or the color of a [callout](/writing/markdown/#callouts) with a `variant`: `note`, `tip`, `success`, `warning` or `danger`.

```mdx
---
title: Search
sidebar:
  badge: New
---
```

```mdx
---
title: Legacy API
sidebar:
  badge:
    text: Deprecated
    variant: warning
---
```

## Pagination

The links at the bottom of a page follow the sidebar order. `prev` and `next` change them: `false` hides a link, a string changes its label, and `link` points it somewhere else, written from the root of the site like any other link:

```mdx
---
title: Deployment
prev: false
next:
  label: Read the changelog
  link: /changelog/
---
```

## Extending the schema

With the integration, `docsSchema()` returns a Zod object, so you can add your own fields and read them from `Astro.locals.zenith.entry.data` in an [override](/customization/overrides/) or a [slot](/customization/slots/):

```ts title="src/content.config.ts"
import { z } from 'astro/zod';

const schema = docsSchema().extend({
  authors: z.array(z.string()).optional(),
});
```
